按钮 Button

按钮用于触发明确的即时操作。

字段提示

只需要图标、文本和主色；响应式、材质与交互反馈由按钮内建。

字段名变量名类型说明
图标iconurl / sf_symbols_nameSF Symbol 直接写名字，例如 checkmark；自定义图标传 URL
文本labeltext简短、明确地描述按钮动作
主色colorhex / text使用系统颜色名（如 blue、gray、red），也可填写 HEX 自定义颜色

模板

按操作语义选择预设；每个模板都由 SF Symbol 名称、文本与颜色组成。

快速上手

输入 SF Symbol 名称或自定义图标 URL，搭配文本与颜色实时预览。
