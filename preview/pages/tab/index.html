主导航 Tabs

使用图标化 Tabs 切换应用一级视图；项目 ID 是从 0 开始的数字索引，窄屏会自动收纳为可展开的 picker。

字段提示

只需提供导航数量、图标数组与当前索引；材质、交互反馈和响应式由组件统一处理。

字段名变量名类型说明
导航数tabsnumber显示的导航项数量，通常与 items.length 一致
导航项目itemsarray按顺序填写 SF Symbol 名称，也可使用对象补充无障碍名称
当前项目activeIdnumber从 0 开始的当前项目索引；每项的 id 自动使用其数组索引

模板

两个常用模板分别对应 EchoGallery 一级导航和媒体类型筛选。

快速上手

编辑导航数量、SF Symbol 名称和当前索引；也可以点选导航，观察数字索引与代码同步。

点击任一导航项，当前数字索引会同步到 activeId。
